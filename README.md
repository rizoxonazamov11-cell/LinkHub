# 🔗 Personal Link Hub (Linktree Muqobili)

Zamonaviy, minimalistik, estetik va to'liq moslashuvchan (responsive) shaxsiy havolalar sahifasi.

## ✨ Xususiyatlari
- **Dizayn & UI/UX**: Zamonaviy Glassmorphism effekti, mayin gradient fon va silliq hover animatsiyalari.
- **Dark / Light Mode**: Qorong'i va yorug' rejim tugmasi, tanlangan mavzu `localStorage`da saqlanadi va qurilmaning tizim mavzusini avtomatik aniqlaydi.
- **Havola kartalari (Link Cards)**: Telegram, GitHub, LinkedIn, Instagram, Shaxsiy Portfolio va Email uchun alohida brend rangidagi kartalar.
- **Ulashish (Copy Link)**: Sahifa havolasini bir bosishda nusxalash va chiroyli animatsiyali Toast bildirishnomasi.
- **Tez va engil**: Tailwind CSS CDN va FontAwesome 6 ikonalaridan foydalanilgan. Hech qanday murakkab build talab qilinmaydi.

## 🚀 Ishga tushirish
1. `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) ikki marta bosib ochishingiz mumkin.
2. Yoki VS Code dasturida **Live Server** kengaytmasi orqali ishga tushirishingiz mumkin.

## 🛠 Moslashtirish (Shaxsiylashtirish)
- **Ism va Bio**: `index.html` ichidagi `Ali Valiyev` va uning ostidagi tavsif matnlarini o'zingizga moslang.
- **Avatar rasmi**: `<img>` tegidagi `src="..."` manziliga o'z rasmingiz havolasini yoki mahalliy rasm nomini qo'ying.
- **Ijtimoiy tarmoq havolalari**: `<a>` teglaridagi `href="..."` parametrlariga o'zingizning Telegram, Instagram, GitHub va LinkedIn profillaringiz havolalarini kiriting.
